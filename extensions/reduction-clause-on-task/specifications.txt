Difficulties for specifying with current OpenMP specifications:
    - 'depend' synchronizes tasks.
    - 'reduction' rewrites data environments
We want a clause on the task construct that do boths.

Question: what should be the behavior of this?
```
int x;

# pragma omp task reduction(+:x)    // default is 'shared' on 'x'
    x += 1;

# pragma omp task depend(in: x)     // default is firstprivate(x), should the user explicitly set shared(x) for this to work ?
    putc(x);

# pragma omp taskwait
```


Maybe another way around is to define 'reduction' on the 'access' clause instead:
```
# pragma omp task access(reduction: x)
    x += 1;

# pragma omp task access(read: x)
    putc(x);
```
