# Contributing to XKOMP
We welcome any form of contributions to XKOMP, and more generally to the [XKRT](https://github.com/anlsys/xkrt) parallel programming environment.
Note that `XKOMP` is primarly a research software and may be unstable.

## Bug reports, Feature Requests
Please open issues at [https://github.com/anlsys/xkomp/issues](https://github.com/anlsys/xkomp/issues)

## Testing
The repository includes a few minimal [tests](https://github.com/anlsys/xkomp/blob/main/tests) that can be extended.
